AnimaWorks is a long-running FastAPI/Uvicorn server with WebSocket, SSE, APScheduler background jobs, APS heartbeat loops, and persistent ChromaDB vector storage at /root/.animaworks. It runs 24/7 with multi-process agent supervision (ProcessSupervisor), so Cloud Run with minInstances=1 keeps the org alive between requests. Memory bumped to 2Gi and 2 vCPU to accommodate sentence-transformers, ChromaDB, diffusers, and concurrent Anima child processes.
