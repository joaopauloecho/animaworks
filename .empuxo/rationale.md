Single-service Python monolith: FastAPI dashboard + Workspace static app + supervisor spawning per-Anima child processes over local IPC. The design assumes shared in-process state (StreamRegistry, RoomManager, ProcessSupervisor) and shared filesystem data dir, so splitting into multiple services would break the IPC model. One Cloud Run service with min=1 preserves heartbeat/cron/consolidation loops; persistent storage for ~/.animaworks should be mounted via a GCS Fuse or a VM migration if durability is needed — flagged for operator review.
